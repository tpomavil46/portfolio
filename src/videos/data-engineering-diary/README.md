## Naming Convention
- Use descriptive names: `01-databricks-intro.mp4`
- Include episode numbers for series order
- Keep file sizes under 100MB for optimal performance

## Thumbnails
- Create thumbnails for each video
- Place in `videos/thumbnails/` directory
- Match video filename: `01-databricks-intro-thumb.jpg`

## Content Guidelines
- Keep videos 15-30 minutes long
- Include hands-on demonstrations
- Show real-world use cases and projects
- Provide downloadable code and configurations
- Include performance benchmarks and best practices
