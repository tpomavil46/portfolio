# Python Programming Diary

This directory contains videos for the Python Programming Diary series, covering from fundamentals to advanced OOP and OOD concepts, including CLRS algorithms, design patterns, and SOLID principles.

## Video Series Structure

### Fundamentals Series
- **01-python-basics.mp4** - Variables, data types, control structures
- **02-functions-intro.mp4** - Function definition, parameters, scope
- **03-data-structures.mp4** - Lists, dictionaries, sets, tuples
- **04-control-flow.mp4** - Loops, conditionals, error handling

### Intermediate Series
- **05-modules-packages.mp4** - Import system, package management
- **06-file-handling.mp4** - Reading/writing files, context managers
- **07-exceptions.mp4** - Exception handling, custom exceptions
- **08-decorators.mp4** - Function decorators, property decorators

### Advanced OOP Series
- **09-classes-basics.mp4** - Class definition, methods, attributes
- **10-inheritance.mp4** - Single and multiple inheritance
- **11-polymorphism.mp4** - Method overriding, abstract classes
- **12-encapsulation.mp4** - Data hiding, getters, setters

### CLRS Algorithms Series
- **13-sorting-algorithms.mp4** - Bubble, selection, insertion, merge, quick sort
- **14-searching-algorithms.mp4** - Linear, binary, depth-first, breadth-first search
- **15-graph-algorithms.mp4** - Dijkstra, Bellman-Ford, Floyd-Warshall
- **16-dynamic-programming.mp4** - Memoization, tabulation, common DP problems
- **17-greedy-algorithms.mp4** - Greedy approach, activity selection, Huffman coding
- **18-divide-conquer.mp4** - Divide and conquer strategy, merge sort, quick sort

### Design Patterns Series
- **19-design-patterns-intro.mp4** - What are design patterns, when to use them
- **20-creational-patterns.mp4** - Singleton, factory, abstract factory, builder
- **21-structural-patterns.mp4** - Adapter, bridge, composite, decorator, facade
- **22-behavioral-patterns.mp4** - Observer, strategy, command, template method
- **23-python-specific-patterns.mp4** - Context managers, decorators, metaclasses

### SOLID Principles Series
- **24-solid-principles-intro.mp4** - Overview of SOLID principles
- **25-single-responsibility.mp4** - Single Responsibility Principle (SRP)
- **26-open-closed.mp4** - Open/Closed Principle (OCP)
- **27-liskov-substitution.mp4** - Liskov Substitution Principle (LSP)
- **28-interface-segregation.mp4** - Interface Segregation Principle (ISP)
- **29-dependency-inversion.mp4** - Dependency Inversion Principle (DIP)
- **30-solid-in-practice.mp4** - Real-world SOLID examples and refactoring

### Advanced Concepts
- **31-testing.mp4** - Unit testing, pytest, TDD
- **32-documentation.mp4** - Docstrings, type hints, documentation
- **33-best-practices.mp4** - Code organization, PEP 8, clean code
- **34-performance-optimization.mp4** - Profiling, optimization techniques
- **35-design-principles.mp4** - DRY, KISS, YAGNI principles

## Naming Convention
- Use descriptive names: `01-python-basics.mp4`
- Include episode numbers for series order
- Keep file sizes under 50MB for optimal performance

## Thumbnails
- Create thumbnails for each video
- Place in `videos/thumbnails/` directory
- Match video filename: `01-python-basics-thumb.jpg`

## Content Guidelines
- Keep videos 10-20 minutes long
- Include practical examples and exercises
- Show real-world applications
- Provide downloadable code examples
- Include algorithm visualizations for CLRS topics
- Demonstrate design patterns with real use cases
- Show before/after code examples for SOLID principles
